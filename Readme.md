# Telco Customer Churn Analysis

End-to-end customer churn analysis using Python, SQL, Excel, and Power BI.

## Project Status

🚧 In Progress

## Tools

- Python
- SQL
- Excel
- Power BI

## Business Problem

This project analyzes customer churn to identify high-risk customer segments,
understand the factors associated with churn, and estimate the potential
monthly revenue impact.
